# Word Pedigree

A searchable etymology application with recorded ancestry, language history, first attestations, related words, and sources. The interface uses sculpted brass, ivory parchment, and inked calligraphy.

## Run locally

Use Node.js 22.12 or newer.

```sh
npm install
npm run dev
```

Open **http://127.0.0.1:5173**. The development server uses a fixed port and accepts only local connections.

```sh
npm run build       # Type-check and build into dist/
npm run preview     # Serve the production build locally
npm test            # Dictionary interpretation and data integrity tests
```

## Explore

- Search an English word, or try nostalgia, serendipity, petrichor, companion, and melancholy.
- Select a framed word to read its historical note.
- Select **Sources** for references and dating notes.
- Use **Save word** to store an entry in this browser.
- Adjust diagram magnification; wider trees can scroll horizontally.
- Share a word through its `?word=nostalgia` URL. Browser back and forward navigation are supported.

## Sources and interpretation

Five prepared plates are editorial summaries with source links. Other searches use the public English Wiktionary API without an API key. Trees come from structured ancestry or explicit derivation clauses in the first English etymology. Inflected forms follow their recorded base entry. Comparisons and cognates are excluded from ancestry; uncertain derivations stay marked. Missing entries and unrecorded origins receive a diagram showing the gap in the source, never invented roots. Abbreviated trees are labelled. Live lookup requires internet access, while prepared entries remain usable when dictionary networking fails.

Relations distinguish descendants, shared roots, related terms, and semantic neighbours. A reconstructed form keeps its asterisk; uncertain ancestry and calques use dotted connections. Live first-use dates are shown only when a source explicitly dates the selected sense.

Wiktionary material is attributed in each entry under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Consult the original page for its contributors and revisions. [Ballet](https://fontsource.org/fonts/ballet) and [Imperial Script](https://fontsource.org/fonts/imperial-script) are self-hosted through Fontsource; their SIL Open Font Licenses are included in `public/licenses/` and the production build.

## Implementation

React, TypeScript, and Vite. Three.js renders a continuous metal frame with 70px mouldings on large screens, scaling down to approximately 34px on phones. Circular corner shoulders and an integral crest support the ornament. Original acanthus, rose, laurel, shell, scroll, egg-and-dart, and cherub models form a relief die. `src/rendering/engravedFrame.ts` uses that die to cut the decoration into the frame's surface: even the highest parts of the carvings sit below the uncut metal. Fine incisions have additional depth. Surface normals, cavity patina, metal roughness, and directional shadows give the grooves their shading. The four adjoining rail meshes render on demand.

Carving detail is sampled in narrow strips at three samples per CSS pixel, keeping the feather cuts and leaf veins sharp on long pages. Smooth moulding profiles and denser relief geometry preserve the curved highlights. A fine rolled inner lip sits against the paper, with a shallow engraved leaf trail around its moulding; a narrow contact shadow follows the same curved opening, independently of the metal's shadow-map resolution. The brass shader concentrates mottled umber patina in sheltered recesses and varies roughness around lightly polished edges; sparse pitting and short polishing marks break up the surface.

The parchment shader derives surface normals from broad undulations, compressed fibres, and fine surface tooth. Grazing light reveals that relief; uneven sizing, pores, oxidation, and sparse foxing keep a consistent scale as the page grows. Warm ivory, rose-grey hollows, and muted brown edge stains age the sheet without a uniform yellow wash. Ballet supplies the ceremonial masthead; Imperial Script supplies the words and annotations. `InkText` paints those letterforms with variable pigment concentration, warmer washes, darker drying edges, and capillary bleed. A distance field follows the curved stroke boundaries to place fine bristle traces within broad strokes while preserving the hairlines. Generous canvas margins accommodate sweeping capitals and descenders. Native scripts and phonetic symbols retain their characters; underlying text stays selectable and accessible. An SVG absorption filter adds pigment variation and pooled stroke margins to smaller annotations, controls, source notes, and dialogs.

`lace-frame.svg` is a single nine-slice border with dedicated curved corner panels, continuous ground, and picots following the edge. It is generated by `scripts/generate_lace.py`. The same script creates a transparent, seamless 192px linen repeat over a continuous blush background on the root element, including the page margins.

Two dried pink statice sprigs sit on the linen and disappear beneath the outer rails. `src/rendering/driedSprigs.ts` models fluted, winged stems, curled leaves, irregular five-fold calyces, and faded cream centres, using original geometry and procedural fibre textures. Directional light and contact shadows give the papery blooms their depth. The still life renders once into two canvases and releases its temporary WebGL context; detailed SVG substitutes remain available without WebGL. The decoration is clipped outside the reading area, has no pointer interactions, and is hidden from assistive technology.

### Design references

The ornament is an interpretation of historical revival work. Motif construction is guided by [Getty’s frame conservation examples](https://www.getty.edu/news/whats-in-a-frame/) and the [Met’s nineteenth-century gilt cornice](https://www.metmuseum.org/art/collection/search/2272). The turning floral lace border refers to the [Met’s mid-nineteenth-century French handkerchief, 48.187.649](https://www.metmuseum.org/art/collection/search/227371). The dried sprigs refer to [RHS botanical notes on Limonium](https://www.rhs.org.uk/plants/131084/limonium/details), [Kwantlen Polytechnic University’s statice morphology](https://plantdatabase.kpu.ca/Plant/lisi), and [photographs of dried pink statice](https://www.floristik24.at/gefluegelter-strandflieder-getrocknet-limonium-sinuatum-statice-blau-68cm-40g). The site artwork is original SVG and geometry; reference photographs are not used as interface assets.

CSS and SVG remain visible if WebGL is unavailable or the frame loses its graphics context. Reduced-motion preferences are respected; dialogs support keyboard focus and Escape.

Original SVG assets live in `public/ornaments/`. Rebuild them with `python3 scripts/generate_ornaments.py`; material definitions are in `scripts/generate_materials.py`. No image generation is used.

Run `node scripts/verify-browser.mjs` with the development server running for browser checks and desktop/mobile screenshots. It uses Playwright Chromium (`npx playwright install chromium` if needed), writes ignored artifacts to `test-results/`, and includes one live Wiktionary request.

The application code and original artwork are available under the repository's MIT license. Dictionary material and fonts retain their separate licenses. The initial version is maintained in [wildfellhall/WordPedigree](https://github.com/wildfellhall/WordPedigree).
