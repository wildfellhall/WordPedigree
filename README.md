# Word Pedigree

A searchable etymology application with recorded ancestry, language history, first attestations, related words, and sources. The interface uses sculpted brass, ivory parchment, and inked calligraphy.

## Run locally

Use Node.js 22.12 or newer.

```sh
npm install
npm run dev
```

Open **http://127.0.0.1:5173**. The development server uses a fixed port and accepts only local connections.

```sh
npm run build       # Type-check and build into dist/
npm run preview     # Serve the production build locally
npm test            # Dictionary interpretation and data integrity tests
```

## Explore

- Search an English word, or try nostalgia, serendipity, petrichor, companion, and melancholy.
- Select a framed word to read its historical note.
- Select **Sources** for references and dating notes.
- Use **Save word** to store an entry in this browser.
- Adjust diagram magnification; wider trees can scroll horizontally.
- Share a word through its `?word=nostalgia` URL. Browser back and forward navigation are supported.

## Sources and interpretation

Five prepared plates are editorial summaries with source links. Other searches use the public English Wiktionary API without an API key. Trees come from structured ancestry or explicit derivation clauses in the first English etymology. Inflected forms follow their recorded base entry. Comparisons and cognates are excluded from ancestry; uncertain derivations stay marked. Missing entries and unrecorded origins receive a diagram showing the gap in the source, never invented roots. Abbreviated trees are labelled. Live lookup requires internet access, while prepared entries remain usable when dictionary networking fails.

Relations distinguish descendants, shared roots, related terms, and semantic neighbours. A reconstructed form keeps its asterisk; uncertain ancestry and calques use dotted connections. Live first-use dates are shown only when a source explicitly dates the selected sense.

Wiktionary material is attributed in each entry under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Consult the original page for its contributors and revisions. [La Belle Aurore](https://fontsource.org/fonts/la-belle-aurore) by Kimberly Geswein is self-hosted through Fontsource; its SIL Open Font License is included in `public/licenses/` and the production build.

## Implementation

React, TypeScript, and Vite. Three.js renders the frame as 3D geometry: profiled mouldings, lobed acanthus, layered roses, tied laurel garlands, fluted shells with hinge ears, connected volutes, an instanced egg-and-dart border, and a sculpted cherub. Pierced running scrolls have round wire sections, twisted strands, and raised leaf terminals. Metallic materials use environment lighting, directional shadows, surface roughness, and bump texture. Carvings are merged by material to reduce draw calls; the scene renders on demand.

The parchment shader derives surface normals from broad undulations, compressed fibres, and fine surface tooth. Grazing light reveals that relief; uneven sizing, pores, oxidation, and sparse foxing keep a consistent scale as the page grows. La Belle Aurore supplies the handwriting throughout. `InkText` paints those same letterforms with uneven pigment, darker stroke margins, and capillary bleed. Small changes in pen angle happen between words, preserving cursive joins. Native scripts and phonetic symbols retain their characters; underlying text stays selectable and accessible. Smaller text uses an SVG absorption filter.

`lace-frame.svg` is a single nine-slice border with dedicated curved corner panels, continuous ground, and picots following the edge. It is generated by `scripts/generate_lace.py`.

### Design references

The ornament is an interpretation of historical revival work. Motif construction is guided by [Getty’s frame conservation examples](https://www.getty.edu/news/whats-in-a-frame/) and the [Met’s nineteenth-century gilt cornice](https://www.metmuseum.org/art/collection/search/2272). The turning floral lace border refers to the [Met’s mid-nineteenth-century French handkerchief, 48.187.649](https://www.metmuseum.org/art/collection/search/227371). The site artwork is original SVG and geometry; reference photographs are not used as interface assets.

CSS and SVG remain visible if WebGL is unavailable or the frame loses its graphics context. Reduced-motion preferences are respected; dialogs support keyboard focus and Escape.

Original SVG assets live in `public/ornaments/`. Rebuild them with `python3 scripts/generate_ornaments.py`; material definitions are in `scripts/generate_materials.py`. No image generation is used.

Run `node scripts/verify-browser.mjs` with the development server running for browser checks and desktop/mobile screenshots. It uses Playwright Chromium (`npx playwright install chromium` if needed), writes ignored artifacts to `test-results/`, and includes one live Wiktionary request.
